# universal-roastbot
 RoastBot Universal (Beta)  Adds a smart roast button to text fields across websites, letting you generate quick, dynamic replies instantly.  Uses combination-based roasts with optional translation for global use. Early beta — works on most sites but may vary. 
## Install

1. Download this repo (Code → Download ZIP)
2. Extract the folder
3. Go to chrome://extensions
4. Turn ON Developer Mode
5. Click "Load unpacked"
6. Select the folder

✅ Done – Roast button will appear automatically
